# Online Food Delivery Analysis

An end-to-end data analytics project exploring 100,000 online food delivery orders. The project covers data cleaning, exploratory analysis, feature engineering, MySQL storage and querying, and interactive dashboards built with Streamlit and Power BI.

## Project Overview

This project analyzes customer orders, revenue, cancellations, payment choices, and delivery performance. Python and Jupyter Notebook are used to prepare and explore the data. The cleaned, feature-engineered data is stored in MySQL and used for SQL analysis and dashboard reporting.

## Project Goals

- Prepare the raw order data for analysis.
- Investigate customer, revenue, cancellation, and delivery patterns.
- Store the prepared data in a MySQL table and query it with SQL.
- Present key metrics and findings in dashboards.

## Tools and Technologies

- **Python** — data preparation and analysis
- **Pandas and NumPy** — data handling and calculations
- **Jupyter Notebook** — analysis workflow and SQLAlchemy queries
- **MySQL** — database storage and querying
- **SQLAlchemy** — connection between Python and MySQL
- **Streamlit** — interactive web dashboard
- **Power BI Desktop** — two-page dashboard
